# Magic Gamma Classification

This project builds a machine learning model to classify gamma vs hadron events using the MAGIC Gamma Telescope dataset.

## Overview

* Loaded and explored the dataset using Pandas
* Preprocessed data with feature scaling (StandardScaler)
* Handled class imbalance using RandomOverSampler
* Trained multiple models (KNN, Logistic Regression, SVM)
* Built and optimized a neural network using TensorFlow
* Performed hyperparameter tuning to find the best model
* Evaluated model performance using accuracy and classification metrics

## Tech Stack

* Python
* NumPy, Pandas
* Scikit-learn
* TensorFlow
* Matplotlib

## Project Workflow

1. Data loading and cleaning
2. Exploratory data analysis (visualization)
3. Data preprocessing (scaling and balancing)
4. Model training and comparison
5. Neural network tuning
6. Model evaluation

## Results

* Best model selected based on validation loss
* Used accuracy and classification report for evaluation
